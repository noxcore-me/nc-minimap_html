# nc-minimap_html

nc-minimap map style assets.

Each zip is a complete `nc-minimap` resource with one bundled map style.
Extract into your `resources/` folder and `ensure nc-minimap`.

| Style | File |
|---|---|
| Atlas | `nc-minimap-styleAtlas.zip` |
| Atlas Postal | `nc-minimap-styleAtlasPostal.zip` |
| Black | `nc-minimap-styleBlack.zip` |
| Black & White | `nc-minimap-styleBlackWhite.zip` |
| Satmap | `nc-minimap-styleSatmap.zip` |
| Satmap Grid | `nc-minimap-styleSatmapGrid.zip` |

Docs: https://docs.noxcore.me/nc-minimap
